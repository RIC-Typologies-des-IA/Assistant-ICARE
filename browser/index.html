PRÉFÉRENCES LOCALES

Moteurs d'inférence

ICARE utilise deux modèles indépendants : le premier comprend et traite les échanges écrits ; le second transforme la voix en texte (Whisper ou modèle compatible). Ils peuvent provenir de fournisseurs différents.

1. Modèle de traitement du texte

Choisissez un fournisseur pour afficher son adresse et ses consignes spécifiques.

Guide de connexion et de configuration CORS

ICARE est hébergé sur GitHub Pages. Pour un moteur local, le serveur doit autoriser cette origine exacte : https://ric-typologies-des-ia.github.io.

Claude (Anthropic) utilise une API Messages différente de Chat Completions : il nécessite un adaptateur dédié, non fourni dans cette version. Son accès direct depuis un navigateur est soumis à des restrictions de sécurité propres à Anthropic. Documentation Anthropic sur les appels navigateur.

2. Modèle de transcription audio

Pour OpenAI, utilisez l’API Audio Transcriptions et un modèle tel que whisper-1. Le fournisseur doit exposer un endpoint compatible /audio/transcriptions.

La configuration est indépendante du modèle de dialogue. Le branchement de la dictée dans le champ de saisie sera activé par le composant micro ; ici, vous définissez déjà le moteur et son endpoint.

Confidentialité : les clés ne sont jamais ajoutées aux exports. Le stockage navigateur n'est pas un coffre-fort contre un appareil compromis. Les textes et fichiers audio envoyés sont transmis directement au fournisseur concerné.
