    Configuration des moteurs
    

    Choisissez d’abord le mode de configuration. Les moteurs directs et les passerelles sont configurés dans des espaces distincts.
    

    



    

    

    Les services configurés ici sont accessibles directement depuis ce navigateur : API locale sur votre machine ou fournisseur direct distant selon l’adresse renseignée.
    

    Inférence locale · Traitement du texte
    API compatible OpenAI Chat Completions. localhost désigne votre propre ordinateur.
    La clé est chiffrée localement avec AES-GCM et conservée dans le profil de ce navigateur.
    

    Transcription locale · Audio
    L’API doit exposer /v1/audio/transcriptions. Pour que la voix reste sur votre appareil, utilisez un serveur sur localhost ou 127.0.0.1. Un fournisseur direct distant recevra lui aussi l’enregistrement vocal.
    La clé est chiffrée localement avec AES-GCM et conservée dans le profil de ce navigateur. Ce moteur est indépendant du moteur texte. Pour Lemonade + NPU, choisissez Whisper v3 Turbo FastFlowLM : les modèles Whisper.cpp ne sont pas compatibles avec la coexistence NPU recherchée. Après configuration, testez dans cet ordre : scoring D3, transcription, puis scoring D3 à nouveau. Le dernier test doit réussir sans éviction du modèle de décision.
    Documentation officielle Lemonade — API de transcription audio · Catalogue des modèles disponibles
    

    Scoring ICARE (multilabel)
    


    


    

    La liste est interrogée directement auprès de Lemonade. ICARE ne propose que les modèles FastFlowLM déclarant les capacités « classification » et « systemone ». Le scoring utilise cinq questions indépendantes sur /v1/systemone ; aucune génération de texte ni inférence distante n’est nécessaire. D3 Ultra exige FastFlowLM 1.0.11 ou ultérieur et environ 28 Go de mémoire libre ; des variantes D3 plus petites peuvent être choisies si nécessaire. Depuis l’application ICARE hébergée sur GitHub Pages, autorisez son origine dans Lemonade : lemonade config set allowed_origins="https://ric-typologies-des-ia.github.io".
    

    

    Le service externe doit renvoyer cinq scores indépendants compris entre 0 et 1 (I, C, A, R, E).
    


    Si Lemonade a une clé API configurée, elle est envoyée uniquement à votre serveur local. La clé est chiffrée dans le coffre du navigateur.
    

    

    Confidentialité : un fournisseur distant reçoit les données du service concerné. Avec un moteur local, ces données restent sur votre appareil. Les clés locales sont chiffrées et ne sont jamais incluses dans les exports.
